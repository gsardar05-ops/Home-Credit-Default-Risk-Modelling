# Home Credit Default Risk Modelling

## Project Overview

This project builds an end-to-end credit risk modelling framework using the Home Credit Default Risk dataset.

The objective is to predict whether a loan applicant may face repayment difficulty and to build a structured Probability of Default modelling workflow.

## Planned Workflow

1. Data understanding
2. Application train EDA
3. Missing value and feature type analysis
4. Baseline Probability of Default model
5. Feature engineering
6. Model validation
7. Expected loss framework

## Dataset

Dataset used: Home Credit Default Risk dataset from Kaggle.

Raw data files are not uploaded to this repository. Users should download the dataset separately and place the files inside:

```text
data/raw/
```
